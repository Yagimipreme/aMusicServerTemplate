**Conventions:** TDD for every backend task. UI tasks end with a concrete manual-verify step (curl + browser). One commit per task; `git add` only changed files (config.json is gitignored; never `git add -A`).

### Task 2: `GET /yt/search`

**Files:** Modify `sWebExt/py_server/server.py`; extend `tests/server/test_routes.py`

- [ ] Failing tests: missing `q` → 400; happy path (monkeypatch `subprocess.run` to return a fake `ytsearch` flat JSON) → `{"results":[{"source":"yt","title","artist","duration","url"}]}`; subprocess raising/timeout → 200 with `{"results": [], "error": ...}` (never 500).
- [ ] Implement:

```python
@app.route("/yt/search", methods=["GET"])
def yt_search():
    q = (request.args.get("q") or "").strip()
    if not q:
        return jsonify({"status": "error", "error": "q required"}), 400
    limit = max(1, min(25, int(request.args.get("limit", 10))))
    try:
        proc = subprocess.run(
            ["yt-dlp", "--flat-playlist", "-J", f"ytsearch{limit}:{q}"],
            capture_output=True, text=True, timeout=10)
        data = json.loads(proc.stdout or "{}")
        results = [{
            "source": "yt",
            "title": e.get("title") or "",
            "artist": e.get("uploader") or e.get("channel") or "",
            "duration": e.get("duration"),
            "url": e.get("url") or f"https://www.youtube.com/watch?v={e.get('id','')}",
        } for e in (data.get("entries") or []) if e]
        return jsonify({"results": results})
    except Exception as e:
        logger.warning("yt_search failed", exc_info=True)
        return jsonify({"results": [], "error": str(e)})
```

### Task 3: `POST /acquire`

**Files:** Modify `sWebExt/py_server/server.py`; extend `tests/server/test_routes.py`

- [ ] Failing tests: no body/url → 400; `ftp://…` → 400; `https://evil.example/x` → 400 (host not in allowlist); allowed host with download monkeypatched → `{"status":"ok","path":...}`; same URL while its lock held → 409.
- [ ] Implement. Allowed hosts: `youtube.com`, `www.youtube.com`, `youtu.be`, `music.youtube.com`, `soundcloud.com`, `on.soundcloud.com`, `m.soundcloud.com`. Reuse the SAME download entry point the root POST uses — find it in `root_post` (`_run_script(...)` / sTownload path) and extract a callable `_download_url(url) -> str|None` shared by both, so behavior (title cleanup, scan trigger) stays identical. Per-URL in-flight set with a module lock:

```python
_acquire_inflight, _acquire_lock = set(), threading.Lock()
_ACQUIRE_HOSTS = {"youtube.com","www.youtube.com","youtu.be","music.youtube.com",
                  "soundcloud.com","on.soundcloud.com","m.soundcloud.com"}

@app.route("/acquire", methods=["POST"])
def acquire_url():
    body = request.get_json(force=True, silent=True) or {}
    url = (body.get("url") or "").strip()
    if not url:
        return jsonify({"status": "error", "error": "url required"}), 400
    from urllib.parse import urlparse
    p = urlparse(url)
    if p.scheme not in ("http", "https") or p.hostname not in _ACQUIRE_HOSTS:
        return jsonify({"status": "error", "error": "unsupported url"}), 400
    with _acquire_lock:
        if url in _acquire_inflight:
            return jsonify({"status": "busy", "reason": "already downloading"}), 409
        _acquire_inflight.add(url)
    try:
        path = _download_url(url)
        return jsonify({"status": "ok" if path else "error", "path": path})
    finally:
        with _acquire_lock:
            _acquire_inflight.discard(url)
```

- [ ] Green; full suite green. Commit: `feat(server): POST /acquire with host allowlist + in-flight guard`
